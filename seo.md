# 🚀 SEO Technical Checklist

## Optimisation On-Page (HTML)
- **Title Tag** : Entre 50 et 60 caractères.
- **Meta Description** : Entre 140 et 155 caractères.
- **Balises Hn** : Un seul H1 par page, structure logique (H2, H3...).
- **Images** : Toujours ajouter un attribut 'alt' et utiliser le format WebP.

## Fichiers Techniques
- **Robots.txt** : Vérifier que les pages importantes ne sont pas bloquées.
- **Sitemap.xml** : À soumettre dans la Google Search Console.

## Outils de mesure
- **Google PageSpeed Insights** : Pour la vitesse de chargement.
- **Screaming Frog** : Pour détecter les liens morts (404).
