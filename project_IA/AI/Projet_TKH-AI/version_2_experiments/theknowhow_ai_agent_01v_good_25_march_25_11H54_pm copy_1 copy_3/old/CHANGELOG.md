# Changelog

Tous les changements notables de ce projet seront documentés dans ce fichier.

Le format est basé sur [Keep a Changelog](https://keepachangelog.com/fr/1.0.0/),
et ce projet adhère à [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-03-07

### Ajouté
- Phase 1 : Collecte de données
  - Scraper Reddit
  - Gestionnaire de base de données
  - API FastAPI pour la collecte

- Phase 2 : Traitement du langage naturel
  - Processeur de texte
  - Extracteur d'entités
  - Analyseur de sentiment

- Phase 3 : Analyse avancée
  - Classificateur
  - Détecteur de motifs
  - Analyseur temporel
  - Visualiseur

- Phase 4 : Évaluation et reporting
  - Évaluateur de modèles
  - Générateur de rapports
  - Tableau de bord
  - Export de données

### Modifié
- Structure du projet réorganisée
- Documentation améliorée
- Scripts utilitaires ajoutés

### Corrigé
- Problèmes de performance dans le scraper
- Erreurs de validation des données
- Bugs dans l'analyse des sentiments

### Sécurité
- Ajout de validation des entrées
- Amélioration de la gestion des secrets
- Mise à jour des dépendances
