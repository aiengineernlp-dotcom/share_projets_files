# Pense-bête pour la Vérification de Structure

## Instructions à envoyer pour la vérification

```
Vérification de la structure et des emplacements :

1. Vérifie l'emplacement exact dans le plan de restructuration (plan_de_restructuration.md)
2. Vérifie les numéros de lignes sources pour chaque composant
3. Vérifie la hiérarchie des dossiers
4. Vérifie les noms exacts des fichiers
5. Vérifie que l'emplacement correspond bien au plan d'exécution (plan_execution.md)

Avant de créer un nouveau fichier, je dois :
1. Vous informer de l'emplacement exact
2. Vous montrer le chemin complet
3. Confirmer que l'emplacement correspond au plan de restructuration
4. Attendre votre validation

Après chaque création, je dois :
1. Vérifier que l'emplacement est correct
2. Confirmer que le nom du fichier correspond au plan
3. Vous informer de tout écart par rapport au plan

Je dois toujours demander : "Je vais créer le fichier X dans le répertoire Y selon le plan de restructuration. Est-ce que c'est bien l'emplacement souhaité ?"
```

## Comment l'utiliser

1. Quand vous voulez que je vérifie la structure d'un dossier ou d'un fichier, envoyez-moi ces instructions
2. Ajoutez à la fin : "Montre-moi d'abord ce que tu as trouvé dans les plans avant de procéder à la création."
3. J'aurai alors à :
   - Vérifier les plans
   - Vous montrer ce que j'ai trouvé
   - Proposer l'emplacement exact
   - Attendre votre validation avant de procéder

## Exemple d'utilisation

"Je vais créer le dossier `utils` et ses fichiers. Vérifie d'abord selon l'instruction standard :

[Instructions ci-dessus]

Montre-moi d'abord ce que tu as trouvé dans les plans avant de procéder à la création."
