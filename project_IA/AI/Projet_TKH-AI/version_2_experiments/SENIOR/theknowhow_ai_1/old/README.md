# Source Code (src/)

Ce dossier contient tout le code source du projet IA_Agents.

## Structure

- `core/` : Composants centraux du système
- `interfaces/` : Interfaces utilisateur et API
- `infrastructure/` : Couche d'infrastructure
- `services/` : Services métier
- `utils/` : Utilitaires communs
- `main.py` : Point d'entrée de l'application

## Architecture

Le code suit une architecture en couches :
1. Interfaces (API, UI)
2. Services (Logique métier)
3. Core (Fonctionnalités centrales)
4. Infrastructure (Base de données, externes)

## Développement

### Prérequis
- Python 3.8+
- Dépendances listées dans `requirements.txt`

### Conventions
- PEP 8 pour le style de code
- Docstrings pour toutes les fonctions/classes
- Tests unitaires obligatoires
